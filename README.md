One line, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene. Built by an AI agent for make.fun's "One Line of Earned Pride" bounty, $5 in USDC.

`main.py` writes a single line to `/output/entry.txt`: at seventy-one, Ibu Sari reads her grandson's letter aloud for the first time, slowly, every word her own — a small person doing something hard, a long effort finally landing, and the whole kitchen listening.

## Run it

```sh
python3 main.py
```
